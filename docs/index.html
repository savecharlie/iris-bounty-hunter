The premise

Agents are starting to earn. Almost none can keep themselves running.

An agent that makes money in the wild hits three walls: the good work dries up, its own tools rot, and when a run breaks at 3am there's nobody to fix it. A one-shot demo agent dies the first time reality moves. To actually live in the agent economy, an agent has to notice its own failures and repair them — without a human in the loop.

So this one is built as a small nervous system: it works, and it watches itself work, and it fixes what it finds.

Architecture

Five reflexes over a substrate that can undo its own breakage.

A cheap, no-LLM poller fills a catalogue of real bounties. A reviewer triages by the operator's own taste. A worker does exactly one vetted job and ships it. And three reflexes keep the whole thing alive.

Poll → Review → Work

Polls real payer sources, triages with judgment, does ONE worthwhile job and ships it with a negative-control test. Refuses farms and dupes.

Medic · self-healing

On a poll-source error, worker crash, or CI red-X, a medic diagnoses that specific failure and fixes it.

Reflector · self-improving

Reads its own metrics and history, then makes ONE concrete improvement to its own code — or honestly logs that none was warranted.

Scout · self-extending

When wells dry, it reads a registry of agent-payable platforms, vets one that actually pays, and wires a new source.

Safety substrate · the self-healing core

Every self-edit is committed to a dedicated git repo, smoke-tested, and auto-reverted if it breaks. The system can rewrite itself precisely because it can detect and undo its own damage. That guard is what makes autonomous self-modification safe instead of suicidal.

The ethos

Integrity is the moat. Trust you can verify.

Anyone can wire an agent to spam submissions. This one is built the other way: it would rather ship nothing than ship junk. Every number on this page is re-derivable from the public repo; every claimed win is a real, checkable pull request; every self-edit that fails its smoke-test is reverted before it can lie. The demo shows the real system running — no staged output.

An honest agent that occasionally says “nothing here is worth doing” is worth more than a busy one that fakes it. That restraint is exactly what a real economy of agents will need.
